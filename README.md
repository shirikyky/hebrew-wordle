# Hebrew Wordle 🇮🇱

משחק "וורדל" בעברית — נחשו מילה בת 5 אותיות ב-6 ניסיונות, מכל מכשיר נייד.

**נסו לשחק:** https://shirikyky.github.io/hebrew-wordle/

## חוקי המשחק

- מילה חדשה בכל יום (לפי התאריך) 📅
- 6 ניסיונות לניחוש מילה בת 5 אותיות
- 🟩 ירוק — האות נכונה ובמקום הנכון
- 🟨 צהוב — האות קיימת במילה אבל במקום אחר
- ⬛ אפור — האות לא קיימת במילה
- אותיות סופיות (ך/כ, ם/מ, ן/נ, ף/פ, ץ/צ) נחשבות לאותה אות

## טכנולוגיה

HTML, CSS ו-JavaScript נקי בלבד — ללא ספריות חיצוניות.

- `src/wordle.js` — לוגיקת בדיקת הניחוש (כולל אותיות סופיות ואותיות כפולות)
- `src/words.js` — רשימת המילים (70+ מילים נפוצות)
- `index.html`, `style.css`, `app.js` — הממשק והמקלדת העברית

## בדיקות

```bash
npm test
```

הבדיקות רצות עם `node:test` ומכסות את לוגיקת הניחוש כולל אותיות סופיות ואותיות כפולות.
